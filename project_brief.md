# My agent: travel-concierge
One-liner: A conversational agent that helps travelers discover destinations and plan trips with a catalog of curated travel experiences.

Tool coverage:
- Memory: User travel style, dietary preferences, budget constraints, and saved itineraries
- Tools: Search destinations, check flight/hotel availability, and retrieve travel weather
- Catalog/UI: Collection of hotel listings and excursion packages rendered as cards
- Image gen: Generating scenic destination preview photos
- Sandbox: Calculating trip budget breakdowns and currency conversions

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for calculations
